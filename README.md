Bienvenue sur le dépôt de mon portfolio personnel ! Ce site web a été conçu pour présenter mon parcours, mes compétences techniques, mes projets et mes certifications de manière moderne et interactive.

## ✨ À propos

Je suis **TALBI SIHAM**, étudiante en 3ème année d'ingénierie informatique à l'**ENSA Fès**, avec une spécialisation en **Intelligence Artificielle et Confiance Numérique**. Ce portfolio est une vitrine de mon travail et de ma passion pour la technologie.

## 🚀 Fonctionnalités Principales

- **Design Moderne et Futuriste** : Une interface utilisateur avec un thème sombre/clair, des effets de néon, un curseur personnalisé et des animations fluides.
- **Section "À propos"** : Une présentation de mon parcours et de mes aspirations.
- **Bannière Interactive** : Un bandeau animé mettant en avant mes statistiques clés (années d'études, certifications, projets).
- **Compétences Détaillées** : Une grille de compétences techniques filtrables par catégorie (Langages, IA/Data, Cloud, Sécurité, etc.) avec des icônes interactives.
- **Expérience Professionnelle** : Une chronologie de mes stages avec description des missions et des technologies utilisées.
- **Certifications** : Une galerie de mes certifications (Cisco, Coursera, etc.) avec possibilité d'agrandir les images.
- **Projets** : Une section présentant mes projets personnels et académiques avec liens vers le code source et les démos.
- **Formulaire de Contact** : Un formulaire fonctionnel pour me contacter directement depuis le site.

## 🛠️ Technologies Utilisées

Ce portfolio est construit entièrement en **HTML, CSS et JavaScript** vanilla, sans framework front-end lourd, pour garantir performance et légèreté.

- **HTML5** : Structure sémantique du site.
- **CSS3** :
    - Mise en page moderne avec Flexbox et Grid.
    - Design responsive pour une expérience optimale sur tous les appareils.
    - Variables CSS pour un thème clair/sombre dynamique.
    - Animations et transitions avancées (effets néon, glitch, particules).
- **JavaScript** :
    - Interactivité complète (thème, filtres, menu mobile).
    - Animation de particules sur la page d'accueil (Canvas API).
    - Animations au défilement (Intersection Observer API).
    - Gestion du formulaire de contact.
- **Bibliothèques Externes** :
    - **Font Awesome** : Pour les icônes.
    - **Google Fonts** : Pour la typographie (`Inter`).
    - **Devicon** : Pour les icônes des langages et technologies.
    - **Formspree** : Pour la gestion de l'envoi du formulaire de contact.
